Chapter 1 Claude Code 是什麼?

⏱ 預估 5 分鐘讀完

💡 一句話講完

Claude Code 是 Anthropic 出的 agentic coding 工具:它直接跑在你的終端機裡,能讀懂整個 codebase、跨檔案改程式、跑指令與測試、操作 git。不是「問它怎麼做、你自己回來敲」,而是「講一次,它自己做完」。

它跟「Claude」是什麼關係

Claude 是 Anthropic 的 AI 模型家族(Opus / Sonnet / Haiku)。Claude Code 則是 Anthropic 官方用這些模型打造的 coding agent —— 把模型接上「能讀寫你檔案、能跑指令」的工具,變成一個會幫你做事的開發夥伴。

在哪裡用?本教學用終端機 CLI

Claude Code 同一套引擎,有好幾種介面,你的 CLAUDE.md、設定、MCP 在各介面通用。先有個印象就好,這份教學從頭到尾用終端機 CLI。

介面 是什麼 本教學
終端機 CLI 在命令列直接跑,功能最完整 ✅ 整份教學用這個
VS Code / JetBrains 編輯器擴充,inline diff、@-mention 之後可自行加裝
桌面 App 獨立視窗,可並行多個 session —
Web(claude.ai/code) 瀏覽器內跑,免本機安裝 —

它跟「純聊天」的 AI 差在哪?

你可能會問:「我已經會用 ChatGPT 問程式問題了,幹嘛還要 Claude Code?」差別在它能不能直接動你的專案:

能力 ChatGPT 網頁 Claude Code
讀你整個 repo ❌ 一次只能貼幾個檔 ✅ 自己讀,不用手動貼
跨多檔改程式 ❌ 只能給你貼回去 ✅ 直接改你的檔(改前先給你看 diff)
跑指令 / 測試 ❌ ✅ 在你的機器上跑,看到結果再修
git(commit / branch / PR) ❌ ✅ 直接幫你做
接外部工具(Jira / Slack / Drive) ❌ ✅ 透過 MCP

換句話說 —— 以前「上 ChatGPT 問怎麼做 → 回 IDE 自己改 → 再上去問下一步」這個來回,在 Claude Code 變成「描述目標,它規劃、跨檔執行、跑測試驗證,再回報給你」。

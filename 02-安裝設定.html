Chapter 2 安裝設定

⏱ 預估 8 分鐘(含下載),小練習 10 分鐘

💡 一句話講完

一行指令裝好 Claude Code,cd 進專案、跑 claude、瀏覽器登入,5 分鐘搞定。跟桌面 App 不同 —— 它沒有「連接資料夾」這個動作,你在哪個目錄啟動,它就在那裡工作。

開始之前

  • 範例專案
  • 一個 Claude 訂閱(Pro / Max / Team / Enterprise)

沒有現成專案的話,複製下面這行,clone 範例 repo 來練習:

git clone https://github.com/business20250626-sudo/claude-cli-demo.git

步驟 1:安裝

原生安裝(官方推薦,會自動背景更新)

macOS / Linux / WSL:

curl -fsSL https://claude.ai/install.sh | bash

Windows PowerShell:

irm https://claude.ai/install.ps1 | iex

步驟 2:啟動 + 登入

到任一個專案目錄啟動:

cd /path/to/your/project
claude

第一次跑會要你登入,照提示在瀏覽器完成認證即可。憑證會存在本機,之後不用每次登入。要換帳號或重新登入,在 session 裡輸入:

/login
✅ 走完 Chapter 2 你要能做到
  • 裝好 Claude Code,終端機打 claude 能啟動
  • 完成瀏覽器登入
  • 知道用 cd 進專案目錄啟動,沒有「連接資料夾」這步
⚠️ 卡關了?

更多安裝問題見官方 installation troubleshooting。

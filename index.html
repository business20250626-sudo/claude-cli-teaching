這份教學是怎麼設計的

每一章聚焦一個概念,搭配一個可以馬上動手的小練習。目標是讓你看完就能把 Claude Code 用在自己的專案上,而不是只停留在「知道有這個工具」。

Chapter 1

Claude Code 是什麼

跑在終端機的 agentic coding 工具 — 跟純聊天 AI、跟 Copilot 補完差在哪,以及有哪些介面。
⏱ 5 min · 🛠 讓它自我介紹你的專案
 Chapter 2

安裝設定

一行指令裝好、cd 進專案、瀏覽器登入,認識提示列與權限模式。
⏱ 8 min · 🛠 啟動 + 讓它讀你的 repo
 Chapter 3

CLAUDE.md

給 Claude 的專案常駐指示 — 用一份檔案寫下規範、慣例與守則,每次 session 自動載入。
⏱ 8 min · 🛠 寫你的第一份 CLAUDE.md
 Chapter 4

Hook

綁在生命週期事件點、到點「一定會跑」的機制 — 跟 CLAUDE.md 的軟性建議互補的硬性保證。
⏱ 8 min · 🛠 看 Hook 必定觸發
 Chapter 5

Skill

按需載入的「能力包」— 平常只有 description 在場,用到才把完整指示拉進來,省 context。
⏱ 8 min · 🛠 建最小 skill 看自動觸發
 Chapter 6

Slash commands

打 / 主動叫用 — 分內建死邏輯指令和 skill,還能用 $ARGUMENTS 吃參數。
⏱ 8 min · 🛠 建吃參數的自訂 command
 Chapter 7

MCP servers

接上外部工具的開放標準(AI 界的 USB-C)— 包一次、到處插,Claude 工作時自己挑工具。
⏱ 10 min · 🛠 接 Notion 看它自己挑工具
 Chapter 8

Subagent

委派出去的專門角色 — 在獨立 context 完成工作後只回報結果,還能鎖死它的工具權限。
⏱ 9 min · 🛠 建唯讀 code-reviewer
 Chapter 9

權限模式

「問你」與「放手」之間的旋鈕 — 日常四模式 Shift+Tab 切,加上 /permissions 規則。
⏱ 9 min · 🛠 同一任務感受三種模式
 Chapter 10

工作流 skill 集

兩套理念相反的 skill 集 — superpowers(強制的開發流水線)vs mattpocock/skills(挑著用的工具箱),怎麼選、能不能並用。
⏱ 9 min · 🛠 各裝一套感受工作流差異
